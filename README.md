\# KAIRO MACROS



\*\*A modern gaming macro utility.\*\*



KAIRO MACROS is a Windows desktop application designed for gaming customization, featuring dedicated support for The Strongest Battlegrounds and Minecraft.



\## Supported Games



\- The Strongest Battlegrounds (Roblox)

\- Minecraft Java Edition



\## Features



\- Modern and lightweight desktop interface

\- Game-specific macro libraries

\- Organized macro categories

\- Custom keybind configuration

\- Visual macro editor

\- Custom profiles and presets

\- Import and export configurations

\- Customizable themes

\- Automatic configuration saving
